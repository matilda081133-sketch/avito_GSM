# Avito AI Recruiter & Bitrix24 Enhancer

Умный автономный ИИ-ассистент рекрутера для платформы Авито и синхронизации с Битрикс24.

## Возможности
1. **Живой диалог в чатах Авито:**
   - Мгновенный ответ кандидату без роботизированных отбивок и без упоминания названий компаний.
   - Считывание готовых анкет Авито (ФИО, возраст, гражданство) без глупых переспросов.
   - База знаний 8 объектов (АБИ Владимир, Тепофол Кашира, Фарма Опалиха, Смарт Балашиха, СДС Химки, Бьюти Москва, Арника Серпухов, СПб Шушары).
   - Точные проверенные маршруты (включая МЦД-4 и автобусы по Салтыковке и Кучино).
   - Честные безопасные ответы про семейные комнаты (без ложных гарантий).
   - Извлечение номера телефона в любом формате.
2. **Авто-обогащение сделок в Битрикс24:**
   - Автоматическое переименование сделок в формат:  
     `[Объект / Вакансия] Имя | Телефон | Возраст (Пол)`
   - Заполнение системных полей: Объект, ФИО, Возраст, Телефон.
   - Перевод на стадию «Квалифицирован / Ждет звонка».

## Быстрый запуск локально
```bash
pip install -r requirements.txt
python main.py
```

## Развертывание в облаке 24/7 (1 клик)
Проект готов для деплоя на любой облачный хостинг:
- **Amvera Cloud / Beget / Timeweb Cloud / Render**
- Порт по умолчанию: `8080`
- Переменные окружения: `B24_WEBHOOK_URL`
